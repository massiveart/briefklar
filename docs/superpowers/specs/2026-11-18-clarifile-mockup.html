So funktioniert's

In vier Schritten zur Erklärung

Dein Brief wird nur für diese eine Anfrage verarbeitet. Was dich persönlich betrifft, bleibt auf dem Server.

1
LesenDie Texterkennung läuft lokal auf dem Server. Dein Foto oder Scan verlässt ihn nicht.
lokal
2
SchwärzenNamen, Adressen, IBAN und Aktenzahl werden durch Platzhalter ersetzt.
lokal
3
ErklärenDie KI sieht nur den geschwärzten Text und schreibt die Erklärung.
Sprachmodell
4
ZurückDeine Daten werden wieder eingesetzt, nur für dich. Gespeichert wird nichts.
lokal

Was die KI zu sehen bekommt

Links ein Ausschnitt aus einem Brief, rechts der Text, den das Sprachmodell tatsächlich erhält.

Dein Briefbleibt hier
Sehr geehrter Herr Max Muster,
bitte überweisen Sie 110,00 Euro auf
das Konto AT61 1904 3002 3457 3201,
Verwendungszweck BHMS-VK-2026/48213.
An das Sprachmodellgeschwärzt
Sehr geehrter Herr ⟦PERSON_1⟧,
bitte überweisen Sie 110,00 Euro auf
das Konto ⟦IBAN_1⟧,
Verwendungszweck ⟦FILE_NUMBER_1⟧.

Betrag und Frist bleiben lesbar, damit die Erklärung stimmt.

Was du bekommst

Geprüfte FristenJede Frist wird mit dem Originalbrief verglichen. Was nicht drinsteht, wird markiert.
Bezahlen per QR-CodeBei Zahlungen ein Code für deine Banking-App, wenn du das möchtest.
Für KI-Assistenten

Auch als MCP-Server

Claude und andere Assistenten können Briefe über Clarifile erklären lassen. Der Brief selbst landet nie beim Assistenten, die Antwort enthält nur Platzhalter.

# Claude Code
claude mcp add --transport http \
